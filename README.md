# Curso OpenMausBot

Mini curso interativo, em português, para entender o OpenMausBot de ponta a ponta: 12 módulos (do primeiro bot até um bot orquestrador), exercícios com checkbox, quiz com correção na hora, glossário pesquisável, busca no curso, tema claro e escuro e progresso salvo no navegador.

- `index.html`: a página publicada, autocontida (CSS e JS inline; só as fontes vêm do Google Fonts).
- `src/`: fonte do conteúdo (`data-1.js`, `data-2.js`), da lógica (`app.js`) e do layout (`template.html`).
- `build.py`: monta o `index.html` a partir de `src/`. Rode `python3 build.py` depois de editar.

Publicar no GitHub Pages: suba o repositório e ative Pages na branch `main`, pasta raiz.

Material independente, baseado na documentação pública em https://docs.openmausbot.com/docs e na versão 0.1.126 do app. Itens marcados "só no código" podem mudar entre versões.
